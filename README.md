# NanoGlobin

NanoGlobin models an ONT amplicon assay as the PCR products generated by a pair
of chromosome haplotypes. It keeps assay observability, molecule evidence,
ambiguity, no-call states, and ground-truth provenance explicit.

## Run the checks locally

Automatic push/PR workflows are disabled in this private repository. Run the
checks on the developer or student workstation and post the output in the PR.

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ".[review]"
python setup.py build_ext --inplace

python -m pytest -q
python scripts/check_evaluation.py
```

Convenience targets:

```bash
make test
make evaluation
make review
```

Render the documents separately:

```bash
quarto render README.qmd
quarto render thesis --to html
quarto render thesis --to typst
```

## Run the public HBA/HBB amplicon smoke test

The repository records all 64 public GridION runs from `PRJNA1439314`. The bounded
smoke test uses `SRR37686269` and `SRR37686273`.

```bash
mamba env create -f envs/public_hbb.yaml
conda activate nanoglobin-public-hbb

make public-hbb-smoke-fetch PUBLIC_HBB_MAX_SPOTS=5000
```

Set the local paths in `config.yml` and provide:

```text
reference/hg38_globin.fa
reference/hg38.fa
reference/ensembl_globin.gff3.gz
models/<matching-Clair3-ONT-model>/
targets.bed
```

Then inspect and run:

```bash
make public-hbb-smoke-dry-run
make public-hbb-smoke-run PUBLIC_HBB_CORES=8
```

This tests the workflow on real public amplicon reads. It does **not** estimate
HBA/HBB sensitivity or specificity because no independent per-sample genotype
table is committed for `PRJNA1439314`.

comparator-only. Coverage or reciprocal interval overlap does not establish a
named HBA gain. The public HBA/HBB reads support workflow mechanics, not analytical
accuracy.

## Public amplicon resources

- `PRJNA1439314`: HBA1/HBA2/HBB/G6PD GridION multiplex-PCR reads; no committed
  individual genotype truth.
- `PRJNA1357883`: CYP2D6/CYP2D7 long-range PCR with validated diplotypes; useful
  for cross-locus genericity.
- `PRJEB88995`: G6PD ONT amplicons with Sanger-confirmed variants; useful for an
  external error-model check.
